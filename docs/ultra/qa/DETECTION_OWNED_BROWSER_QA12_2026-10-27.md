# QA12 源码：检测中心的专用浏览器管理状态

检测中心新增一项真实只读来源：本界面已存在的 Chrome / Firefox 会话管理器。读取不会创建管理器、启动或关闭浏览器、调用助手、发送 CDP / BiDi、请求网页或查询出口。

卡片区分准备、取消、就绪、失败、关闭与清理未确认。清理未知或状态矛盾仍显示无法确认；没有本界面跟踪的会话不证明整个系统没有遗留进程或过滤器。外部浏览器、WebView2 及任意网站的既有未知项不因此变为受保护。

Firefox 原生图形的启动读回记录仅在管理状态就绪且固定聚合范围合法时显示。内容只包含范围与上下文数量，并明确是先前启动检查记录，没有重新测当前站点或 Worker API。缺少 Offscreen API 不被计为匹配。不会导出 session / profile 标识、UA、GPU 字符串、网址、代理或原始错误。

来源读取时间只表示内存状态读取完成，不是流量或页面效果的验证时间；导出继续使用同一已审快照。

验证范围：`internal/detection` 全套纯测试以及 desktop-production 的 `TestOwnedBrowser` 通过。覆盖状态矛盾、未知清理、不扩大外部浏览器证据、无后端创建/调用、聚合范围、原始值不进入序列化和不改变管理器所有权。此文档不是实际 VM 浏览器启动、隔离或界面验收记录。
