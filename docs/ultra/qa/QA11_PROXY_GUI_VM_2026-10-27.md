# qa.11 代理 GUI 与运行中取消授权有限实测（2026-10-27）

本记录来自隔离 Windows VM 中已安装 `0.01-beta-qa.11` 的实际普通 Medium GUI 操作。代理地址、端口、用户名、密码、真实出口 IP、账户、私有路径和原始截图不进入公开文档。本轮整理只更新脱敏文档，没有在开发机运行产品或修改冻结包。

## 认证 SOCKS5 的显式测试

操作员在代理表单手填用户提供的单个认证 SOCKS5 节点，随后显式点击测试。实际界面显示 country.is 返回的出口 IP，与已知代理出口一致；归属地为 US / CA / Los Angeles，当次耗时 1103 ms，`checkedAt=2026-10-26T17:04:39Z`。公开记录不包含该 IP 或节点认证。

随后只在密码末尾追加合成错误后缀。编辑后旧成功结果被隐藏；再次显式测试失败，界面提示没有改用直连。这个失败路径有实际 GUI 观察；“无直连回退”在本批的证据仅为界面、源码和此前 [生产代理模块实测](PRODUCT_PROXY_VM_2026-10-26.md)，本次没有独立捕获 socket 或网络流量，不能宣称已由本轮网络观测证明无回退。

恢复正确认证输入后，产品没有自动再次测试，符合显式触发的交互；但旧失败提示仍残留在 DOM，容易让用户把先前失败误认为当前草稿的结果。这是本次实际发现的 UI 缺陷，已纳入 QA12 源码修复；不回写 QA11，也不把后续源码修复算作已通过真实 GUI 重验。

| 实际操作 | 已观察结果 | 证据范围 |
|---|---|---|
| 手填正确认证并点击测试 | 返回与已知代理相同的出口 IP、上述归属地和时间 | 单节点 SOCKS5 probe 与 GUI / Wails 接线 |
| 修改密码 | 旧成功结果隐藏 | 成功结果随草稿失效 |
| 显式测试错误认证 | 测试失败，界面提示没有改用直连 | 未独立抓包证明无 fallback |
| 恢复正确输入，不点击测试 | 没有自动请求；旧错误提示残留 | QA11 已确认缺陷，QA12 修复后待重验 |

## 运行中重新授权后选择“否”

在已运行的同一普通用户 GUI 中，操作员点击显式管理员授权入口 `PrivacyAuthorize`，接受产品内确认后，在真实 Windows UAC 提示选择“否”。随后 GUI 仍存活、可显示状态；界面显示“用户取消”，并提示“授权未完成，请手动重试”。这验证了本次运行中取消路径的可见反馈与 GUI 保留，补充于 [默认启动取消 UAC 的两轮诊断](QA11_OFFICIAL_UPGRADE_2026-10-27.md)。

本次没有连接隧道，不能据此宣称已验证取消授权不影响正在运行的隧道；也没有取得接受 UAC、替代管理员凭据或助手成功连接的证据。
