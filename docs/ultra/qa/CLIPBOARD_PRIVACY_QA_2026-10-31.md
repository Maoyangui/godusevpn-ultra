# 秘密剪贴板条件清理审计（2026-10-31）

## 当前实现

客户端只有在用户从本应用明确复制订阅凭据时才建立清理回执。回执包含本地序号、内容摘要和所有者信息，清理操作在同一个 Windows 剪贴板锁内核对三项数据；其他程序替换内容后不会清除新内容。默认关闭，时长可选 5–600 秒，关闭应用、取消和“立即清理”都会停止本应用的待处理回执。

## 已复核证据

- `go test ./internal/clipboardprivacy`：通过。
- `go test ./cmd/godusevpn -run 'Test.*Clipboard|Clipboard'`：通过。
- `node docs/ultra/qa/clipboard-ui.cjs`：通过；覆盖默认关闭、时长边界、仅传配置 ID、禁止 JavaScript 直接复制秘密、条件清理、取消、服务不可用和旧页面失效。

## 真实边界

本功能不监听或清空其他程序复制的内容，不撤回其他程序已经读取的副本，也不清理剪贴板历史、云同步或系统外部副本。真实 Windows VM 的竞争、退出和云同步行为仍需在解除 RDP 证书确认后实测，不能用上述纯测试替代。
