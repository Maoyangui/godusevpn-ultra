## 第一步：确认环境，不改网络

在服务器的 Windows PowerShell 中运行随附脚本：

```powershell
powershell.exe -NoProfile -NonInteractive -File .\Inspect-TestEnvironment.ps1
```

脚本位于 `docs/ultra/qa/Inspect-TestEnvironment.ps1`。可复制文件到测试机，也可在云平台“运行命令”中执行文件正文。脚本只输出最少环境 JSON：系统版本、权限类型、固定服务状态、默认浏览器运行时版本及备份是否存在。它不索取订阅，不读取备份内容，不修改设置，也不联网。不存在和无法检查分别表示，不能把 `unknown` 当作未安装或安全。

优先在预期操作 GUI 的交互用户下执行；如果通过云平台执行，结果中的用户上下文和交互令牌只代表该次命令，不能代替桌面用户。脚本只查默认安装和数据位置；自定义位置需另行核对。

## 第二步：建立可操作的管理通道

任选实际可用的一种：

1. 用户打开并登录虚拟机的云平台页面，核对磁盘快照与“运行命令”，再使用云命令执行测试脚本。
2. 已有网页 VNC/控制台时，使用该独立入口操作测试桌面。
3. 在服务器内按微软正式流程启用 OpenSSH，并在 Windows 防火墙和云安全组中仅允许测试来源。先确认握手和身份，再传输测试包；保留可撤销的专用测试密钥，不覆盖已有 SSH 配置或其他管理员的密钥。

不要求提供整个云账号密码。不要为了管理方便关闭 NLA、证书校验、系统防火墙、BFE 或安全防护。新建另一台只有 RDP 的服务器不能解决当前命令通道缺失。

OpenSSH 安装参考：[微软 Windows OpenSSH 文档](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)。

## 第三步：证明能恢复，再做断网测试

先确认快照已成功生成，并知道如何恢复到新磁盘或新虚拟机。独立控制台、VNC 或云运行命令须在 RDP 不可用时仍能使用；仅能重装不等于能恢复现场。

云运行命令虽然独立于 RDP，但仍依赖 VM 代理及网络。Azure 文档说明代理需要 WireServer 通信，运行命令的结果回传也需要出站连接；全局严格闸可能影响这些路径。因此预检执行成功不能证明它能在断网后恢复，须进一步验证真正的串行控制台或可从云控制面恢复的磁盘快照。不要为保住管理通道悄悄增加放行后再宣称原严格模式已通过。[代理网络依赖](https://learn.microsoft.com/en-us/azure/virtual-network/what-is-ip-address-168-63-129-16)、[运行命令限制](https://learn.microsoft.com/en-us/azure/virtual-machines/windows/run-command)。

固定v1测试包有一个恢复兼容性缺陷：纯机器策略仍继承交互用户限制。有已管理的 HKLM 策略时，默认 SYSTEM 身份的云命令无法完成其恢复。新源码已将机器上下文与HKCU分开并加入角色私有存储，见 `qa/MACHINE_RECOVERY_FIX.md`；真实SYSTEM、新包和旧对象显式迁移仍未验收。WFP独立移除不是全部设置恢复证明；在这些门槛通过前，不把 `cleanup-machine` 视作 SYSTEM 下的通用保底。

Azure 默认运行命令身份见[微软文档](https://learn.microsoft.com/en-us/cli/azure/vm/run-command?view=azure-cli-latest)。SSH/WinRM 的实际令牌需要检查，不能只按通道名称推断是否含交互身份。

不得增加宽泛 RDP 放行规则来伪造严格防直连测试通过；不得全局重置防火墙。恢复只撤销本产品明确识别的测试对象，保留其他产品规则。

## 平台边界

- 首选 Windows 11 Pro x64、4 vCPU、8 GB RAM、80 GB 磁盘；Windows Server 可用于服务、WFP 与恢复兼容测试，但不能替代客户端各版本的系统策略验收。Server 需桌面体验才能完整测试 GUI。
- VPS 的虚拟 GPU、远程桌面屏幕与虚拟网卡不能代表真实显卡、Wi-Fi 随机 MAC、GPS、USB、摄像头或麦克风硬件。相关项目仍需本地 VM/实体机补测。
- 独立流量观测端点有助于区分“本机未看到”和“远端确实未收到”；不得用一次连接或公共指纹网站结果推断所有路径安全。
- 完成这些测试后仍须回到 `PROJECT_PLAN.zh-CN.md` 逐项复核；已知未实现功能不因 VPS 测试通过而自动计为完成。
