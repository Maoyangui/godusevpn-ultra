# v0.02

GodUseVPN Ultra v0.02 is the current unsigned Windows x64 preview package. Package names use the short, all-lowercase form `godusevpn-ultra-0.02-windows-amd64.zip`; download the matching `.sha256` file and verify it before extraction.

The v0.02 prerelease is published at <https://github.com/Maoyangui/godusevpn-ultra/releases/tag/v0.02>. The current Windows amd64 ZIP digest is published with the Release asset; download the matching `.sha256` sidecar and verify it before extraction.

The package contains the existing sing-box client plus the Ultra privacy center, detection center, browser environment editor, proxy checks, application rules, metadata tools and recovery records. The release documentation separates source tests, simulated tests and real Windows evidence.

The current release asset was rebuilt from `fdea889` and passed package, ZIP, PE, frontend and checksum audits. The package manifest keeps runtimeVersionVerified=false; the linked VM evidence is separate and does not claim full native browser or GPS acceptance.

The built-in trial action uses `https://godusevpn.org/app/api/trial/*`. The production Cloudflare Worker and GodUseVPN D1 backend have been exercised with status, claim, rotation-safe client replacement, duplicate-claim, CORS and subscription reachability checks. The plan is `free`; the purchase URL is `https://godusevpn.org/subscription/`.

Real native Chrome/Firefox windows and browser proxy egress, GPS provider write/readback, CEF/uBlock, WebRTC/WebGPU/OOPIF/Worker, generic DPAPI credential migration and the full Windows version matrix remain pending wherever the ledgers do not contain evidence. This release does not claim complete anonymity or universal traffic blocking.

Binaries are unsigned. Hashes establish transfer integrity, not publisher identity. WebView2 is required; the build does not install it or change the host network configuration.
