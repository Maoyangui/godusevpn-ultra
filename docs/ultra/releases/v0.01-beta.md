# v0.01 beta

First unsigned Windows x64 beta of GodUseVPN Ultra. Download the ZIP and matching `.sha256`, verify, then fully extract. WebView2 is required. Read the [English README](https://github.com/Maoyangui/godusevpn-ultra#readme) and included recovery guide before installing.

Adds fixed Windows/Chrome/Edge privacy policies, conflict-aware recovery, explicit time-zone selection, separate application WFP rules, a local detection center, a browser companion, JPEG/PNG metadata tools and reviewed exports to the existing sing-box client.

The GUI stays in the original account. Administrator actions use a separate fixed-operation helper. Optional privacy failures do not remove the VPN guard or become connection prerequisites. Official uninstall shares a maintenance gate and preserves recovery tools on failure.

Policy readback and filter existence do not prove traffic blocking or browser acceptance. Localhost, proxy relays, remaining fingerprint signals and version limits are documented. C04's remaining same-account user-store write race is retained in the audit ledger. Detailed diagnostics can remain identifying and require explicit selection and review.

The beta release gate covers fixes and required acceptance of the existing implemented features. First-network prompts, destination allowlists, isolated browser identities and general credential-encryption migration remain roadmap work and are not prerequisites for this release.

Source review, fake/TEMP/DOM checks and real Windows tests are recorded separately in the bundled ledgers. Pending tests remain pending; CI success does not mark real UAC, browser acceptance or traffic behavior as passed. Each candidate's checks and the old v1 policy roundtrip apply only to the exact artifact and actions tested. This release does not claim complete privacy or full cross-version/network certification.

Tag `v0.01-beta`, product/application version `0.01-beta`, numeric Windows file version `0.1.0.0`. Binaries are unsigned; hashes establish integrity, not publisher identity.
