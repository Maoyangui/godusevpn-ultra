# GodUseVPN Ultra Windows 完整执行计划

## 目标与硬约束

1. 在 `godusevpn ultra` 副本中开发 Windows Ultra，原项目目录和文件不改动。
2. 保留原有 VPN、订阅、节点、连接、服务、安装卸载功能；新增能力不得阻断隧道，不得因隐私项失败而回退直连或关闭已有防泄漏保护。
3. 应用默认读取管理员执行资格，但每个写入都必须单独显示范围、影响、备份、读回和恢复状态；服务身份未知时禁止控制请求。
4. 本机不修改网络设置、不安装隧道、不启用 WFP 实验。真实安装、GUI、UAC、隧道、WFP、流量和恢复只在可删除的 Windows VPS 完成。
5. 每项功能使用简洁文本和轻量问号帮助；“已写入”“策略匹配”“规则已装”不得翻译成“已匿名”或“完全阻止读取”。

## 重新核对版总计划（按本轮全部需求）

这份清单是当前执行顺序。它把“可以由 Ultra 自动完成”“需要受控开源组件”“只能检测或引导”分开，避免用一个看似有效的开关代替真实保护。

### B. 开源组件准入清单

1. **locsim**：仅作为位置模拟候选。先核对上游提交、MIT/Apache-2.0 许可证、版本、依赖、默认联网、管理员范围和 SHA-256；不把仓库源码或二进制直接塞进安装包。通过适配器执行“备份 → 应用 → 独立读回 → 冲突检查 → 恢复/卸载”。
2. **CEF/Chromium**：作为第二个浏览器引擎候选。CEF 框架常用 BSD 许可，但随 Chromium 分发的依赖有多种许可证；必须按固定提交完成可复现 Windows 构建、完整 NOTICE/LICENSE、依赖 SPDX/SBOM、沙箱、签名、更新、崩溃处理和体积评估；未通过时只提供 WebView2。
3. **uBlock Origin**：只作为用户主动安装的扩展候选。记录 GPL-3.0、版本、权限、规则列表来源和更新策略；不在用户已有 Chrome/Edge 配置中静默写入，也不把扩展结果当作系统级防护。
4. **系统接口优先**：WFP、Windows 隐私策略、时区、浏览器策略优先使用官方接口和仓库已有实现，不为了“看起来有开源依赖”而引入新的常驻服务。
5. **禁止直接接入的类别**：没有许可证/固定哈希/回滚的 GPS 工具、需要任意 shell 参数的工具、全局硬件噪音注入器、未知来源的反指纹 DLL、会代理或上传浏览数据的组件。它们只能进入路线图或人工评估表。

### C. UI 与文案规则

- 每个卡片只保留：名称、当前状态、一句作用、一个主动作；右侧放轻量 `?`，悬停、点击、键盘聚焦均可打开，Esc 或失焦关闭。
- 推荐短文案：`应用并读回`、`恢复`、`重新检测`、`手动设置`、`需组件`、`仅说明`、`无法确认`。避免“全隐身”“完全防止读取”“已匿名”等承诺。
- 失败文本按原因显示：`需要管理员`、`系统不支持`、`浏览器未接入`、`读回不一致`、`外部已修改`、`恢复未完成`。每条只说明下一步，不堆叠技术术语。
- 可编辑项目使用输入框/选择框；随机参数必须先显示预览和种子；无真实后端的项目不显示可点击开关。
- 检测中心每行固定为“谁能读 / 还能读什么 / 证据 / 下一步”，默认先显示风险最高且最容易处理的项目。

### C.1 权限与检测中心的固定范围

- **权限矩阵**：每个项目分开显示“可读权限、可写权限、机器范围、当前用户范围、企业策略覆盖、观察身份”。只读检测不默认请求 UAC；机器级写入才请求一次 helper/UAC，取消只影响该项目，隧道继续。
- **检测视角**：网络、网站、普通原生应用、Ultra 管理员助手四列分别取证；管理员的读回不冒充普通应用结果，客户端 WebView 不冒充 Edge/Chrome。
- **固定剩余暴露目录**：公网 IP/GeoIP、DNS/IPv6/STUN、时区/语言/地区/字体/屏幕、GPU/WebGL/WebGPU、Canvas/Audio、CPU/内存/电池/触摸、相机/麦克风/传感器/定位、MAC/Wi‑Fi/蓝牙/USB、剪贴板/文件路径/进程/端口、Cookie/Storage/账号、应用遥测/更新/订阅外联。
- 每行都显示“谁能读、还能读什么、证据时间/身份、能否处理、下一步、残余限制”；只读、未知和可能可读不能合并成“安全”。检测默认不联网、不上传指纹、不读取秘密。
- UI 验收覆盖 100/125/150% DPI、窄窗口、键盘操作、高对比度、中英文；GPS 坐标/地点/GPX、浏览器引擎/Profile/参数/种子、WFP EXE/规则类型、时区/语言都必须有值校验、预览、应用读回和恢复路径。

## 产品结构

### 1. 主界面与隐私入口

- 主界面继续负责订阅、节点、连接和流量状态。
- 抽屉增加“隐私中心”和“检测中心”，Windows 桌面显示；Web/Android 不显示假入口。
- Logo 使用方形画布、主体居中、无外圈，`ultra` 为小写粗体艺术字；抽屉保留轻量小写标识。
- 所有卡片按“状态、作用、影响、证据、恢复”排列，问号只补充独有信息。

### 2. 隐私中心

- 系统设置：Windows 广告 ID、输入个性化、剪贴板历史/跨设备同步、浏览器权限、时区等。
- 程序联网：指定 EXE 的 WFP 规则，明确不含回环、代理重发和所有端口扫描。
- 浏览器保护：Chrome/Edge 策略、MV3 扩展、WebRTC 非代理 UDP、WebGL、Cookie、权限和预测请求。
- 数据工具：JPEG/PNG 元数据检查、另存清理副本、诊断预览和脱敏导出。
- 能力与引导：硬件读取、GPS、MAC、WebGPU、Canvas/Audio/字体、账号和站点存储等无法统一保护的范围。
- 可自动修改项只显示“应用并读回”；手动、unsupported、unknown、冲突和恢复未完成项只显示原因和系统入口。

### 3. 检测中心

- 基于当前设置生成本地快照，列出应用或网站仍可能读取的内容。
- 读取方分为网站、应用、网络；结果分为已观察、配置允许、仍有可能、受限、无法确认、需手动检查。
- 检测未知或刷新失败会使旧快照失效，不能继续导出或修改。
- 结果可按范围预览导出；默认排除时区/观察身份，保存的内容必须与预览相同。

## 开源组件集成规则

### 1. GPS/位置模拟

- 评估 locsim 等公开项目；记录仓库、许可证、版本、SHA-256、依赖、默认联网、管理员要求和卸载方式。
- 仓库已先加入 `internal/locationadapter` 的受控边界：没有 HTTPS 来源、批准许可证、固定版本与 SHA-256、管理员授权、备份和独立读回时只显示“需核验”，不下载或执行第三方组件。
- 仅通过固定参数适配器调用，不执行任意用户命令；先备份，再应用、独立读回、冲突检查和恢复。
- 明确只影响 Windows Location Provider、测试覆盖或浏览器 DevTools 的范围；不能改变 GeoIP、Wi-Fi 定位、账号记录或物理 GPS。
- 默认测试/开发模式；启用时显示可能被应用识别为模拟位置；VPS 往返通过后再考虑 beta 集成。

### 2. 系统层工具

- 可复用组件必须通过许可证、来源、构建、哈希、权限、沙箱、回滚和删除审计；没有证据只列路线图。
- 组件失败时保留备份并报告“未完成”，不递归删除、不抢占其他软件的恢复目录、不改变隧道。

## 受控内置浏览器

### 引擎

- 第一阶段 WebView2/Edge：独立 user-data folder、独立 Cookie/权限/代理和可清除生命周期。
- 第二阶段 CEF/Chromium：BSD 许可、独立沙箱和签名；只有资源体积、升级、崩溃和打包门槛通过才加入。
- Firefox/Gecko/QtWebEngine 只有在 Windows 可复现构建、许可证和安全审计通过后才可选择；未安装引擎不显示可选。
- 当前已完成 P1.5 运行时清单：只读发现 WebView2、Edge、Chrome 的注册信息，列出版本与是否可用；CEF 明确显示“本版未提供”。清单不启动、下载或修改浏览器，也不把客户端界面 WebView 当作独立浏览器。
- P3 才显示专用浏览器入口。必须先通过独立 profile、代理绑定、退出清理、参数读回以及断网/断隧道测试；未达到条件时保持说明卡，不显示可点击的伪开关。

### 配置

- 手动配置：UA、语言、地区格式、时区、Accept-Language、Client Hints、权限、WebRTC、WebGL/WebGPU、Cookie、代理/隧道绑定。
- 随机配置：用户选择固定种子，生成内部一致的配置；重新随机必须创建新 profile，并提醒可能增加独特性。
- 不伪造互相矛盾的 GPU 能力、字体、Canvas/Audio、硬件序列号；不把 JS 注入当作全系统保护。
- 启动前展示预览，退出时提供仅清除本产品创建数据的选项；不触碰用户现有 Chrome/Edge profile，不自动登录。

## 架构安全边界

- 隧道生命周期与隐私策略、浏览器 profile、GPS 适配器、WFP 规则分离。
- Connect/Disconnect 使用单事务状态：preparing、starting、connected、stopping、disconnected、error、identity-unknown；stopping 禁止重复点击，identity-unknown 禁止控制请求。
- 隐私策略失败、管理员取消、策略被覆盖、恢复冲突均不会停止隧道、撤销 guard 或回退直连。
- WFP 规则只对明确 EXE 生效；回环、代理、已放行进程、系统服务和端口扫描保持单独说明。
- 日志、诊断、订阅和浏览数据默认最小化；敏感字段仅在用户选择范围并预览后保存。

## VPS 验收顺序

1. 创建 Windows 11 Pro 临时 VM、快照、标准用户和 Bastion；不开放公网 RDP。
2. 传输新包并核对 ZIP、三 EXE 和资源清单哈希；WhatIf 预检。
3. SYSTEM 安装/服务/CLI/卸载安全失败和独立服务清理。
4. 管理员桌面 GUI：隐私中心、检测中心、问号、可应用项和恢复。
5. 标准用户：IPC、权限提示、UAC、用户范围策略和恢复；读回必须独立执行。
6. 浏览器：Edge/Chrome 专用 profile、扩展、WebRTC、权限、语言时区、WebGL/WebGPU、Worker/重启范围。
7. 隧道：连接前后网卡/路由/DNS/IPv6/出口哈希、DNS、TCP、流量；断开后恢复基线。Bastion 或控制通道中断要单独记录，不能伪称产品成功。
8. WFP：先独立观察基线，再应用固定 EXE 规则、读回、流量测试、移除和恢复；失败即保留备份并停止扩展范围。
9. GPS 适配器：仅在 disposable VM 运行组件发现、授权、apply、readback、reset、冲突和卸载。
10. 删除 VM、Bastion、快照、临时传输目录和临时公开文件；确认 Azure 资源组不存在。
