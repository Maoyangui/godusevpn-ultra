# 中断安装与恢复

本beta仅支持全新安装。安装中断后会保留目录，不自动覆盖既有服务或未知文件。中断不能当作安装成功，也没有自动续装或迁移命令。

1. 保留完整可信安装包、已安装文件和全部恢复记录。不要为了消除错误先删备份、清空防火墙或关闭防直连。
2. 关闭Ultra界面与助手，在“服务”中核对精确名称`godusevpn-ultra`。原版`godusevpn`是另一产品，不能只按EXE文件名判断归属。
3. 在完整可信包中运行`Install-Ultra.ps1 -WhatIf`，检查固定目标与完整性。它不会续装或修复半成品。哈希只证明一致性，不证明发布者身份。
4. 如果安装目录中的恢复工具完整且清单/权限校验通过，分别在原用户自己的会话恢复设置。时区先运行`privacy timezone-report`，再明确执行`privacy timezone-restore`；换一个管理员账户不等于原用户。
5. 在安装目录运行`Uninstall-Ultra.ps1 -WhatIf`查看清理范围。实际卸载在同一维护窗口中清理机器项目并移除匹配服务；失败保留工具和记录。不能代替其他用户恢复HKCU，也不能绕过不可信备份。
6. 工具不全、哈希/所有者异常或服务来自另一位置时，停止自动安装，保留副本核查并使用已验证的Windows恢复基线。不接管目录、不强制恢复策略、不递归删除。

清理和恢复经核实后，再单独归档保留的安装目录并重新全新安装。不要移动正在运行的服务文件，也不要删除尚未确认恢复的备份；下一步取决于错误状态和恢复记录。
