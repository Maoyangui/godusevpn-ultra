01 / PRIVACY CENTER

隐私中心，给设置一个清楚的边界。

每个选项都标注作用范围、实际状态和限制。你看到的是证据层级，不是夸大的匿名承诺。

◈

系统与浏览器策略

本地证据

记录观察者身份、读取时间和剩余边界，避免把“已保存”误写成“已阻断”。

↗

安全恢复

写入前保留记录，冲突时保留原值和外部变化，恢复入口轻量且可审计。

02 / BROWSER PROFILE

浏览器环境，像专业多开工具一样可编辑。

为每个浏览器保存独立环境：Windows、macOS、Android、iOS 网页预览，UA 可生成也可手改，GPU/WebGL、CPU、视口和代理都有清晰的真实/自定义边界。

  • 引擎目录 Chrome for Testing / Firefox 版本校验与轻量删除
  • 代理配置 每个浏览器单独设置 SOCKS、HTTP、HTTPS 并测试连通性
  • 启动前复核 修改后预览立即失效，避免带着旧配置启动
