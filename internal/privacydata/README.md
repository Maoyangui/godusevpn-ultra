# 选定图片的本地隐私工具

只处理用户通过本地文件选择器指定的 JPEG/PNG，不扫描磁盘、不联网、不上传、不写源文件，也不在日志或报告中输出 GPS、作者、注释、XMP 等真实值。

```go
report, err := privacydata.Inspect(absoluteSource)
report, err = privacydata.Clean(absoluteSource, absoluteNewDestination)
```

`Report` 的 `metadataBlocks` 表示源图中识别出的指定块类型和块总字节数；`removedBlocks` 表示成功生成副本时删除的块。`hasMetadata` 指源图是否存在这些指定块，不表示文件是否包含任何可能隐私信息。`output` 仅为用户选定的新副本路径，供当前本地界面显示，不应放入诊断导出。

| 格式 | 移除 | 保留 |
| --- | --- | --- |
| JPEG | APP1（Exif/XMP 等整个块）、APP13（IPTC/Photoshop 等整个块）、COM | 原编码像素/扫描数据、ICC APP2 和其他未列出的 APP/标记块 |
| PNG | eXIf、tEXt、zTXt、iTXt | 原 IDAT 编码数据、ICC/颜色配置、其他未列出的合法分块 |

这不是全信息匿名化工具。画面里的人脸、文字、车牌等仍存在；ICC、未列出的附加块、文件名和文件系统属性也可能携带其他信息。移除 EXIF 会同时移除方向标签，部分照片在某些查看器中的显示方向可能改变。不要将结果描述为“已完全清除所有隐私”或“所有元数据已删除”。

输入经过签名、长度和结构检查；JPEG 要求扫描数据和 EOI，拒绝结束后的额外载荷，支持扫描间元数据与转义/重启标记；PNG 验证每块 CRC、IHDR/IEND 结构、IDAT 连续性和块类型。额外使用 Go 标准解码器验证受支持的图像数据，但副本始终按原编码块复制，不重新压缩、不按解码像素重建。单文件最大 256 MiB、最大 4000 万像素、最多 4096 个指定元数据块和 100000 个结构块，超限明确拒绝。未解码验证未知附加块内部的私有格式。

Windows 路径拒绝 UNC、映射网络磁盘、设备/扩展设备路径、ADS、目录、保留设备名、含糊尾点/尾空格和重解析点。源文件通过只共享读取的句柄打开，以防清理期间被写入或替换；实际句柄路径需与用户选择的路径一致（允许普通 8.3 名称展开）。输出使用 CREATE_NEW（O_EXCL 等效）创建；已有文件、硬链接和同名源文件都不会覆盖。失败使用本次创建文件的句柄标记删除，避免按被替换路径误删其他文件。

合成测试覆盖指定块移除、ICC 和非目标字节完整保留、解码前后像素一致、源文件不变、已存在输出拒绝、坏 CRC/截断/尾随数据/无效像素拒绝、元数据块数量上限、错误输出和仅删除本次新输出。测试不使用真实私人照片。
