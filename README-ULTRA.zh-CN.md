这是在独立目录开发的 Windows 增强版本，原项目目录保持不变。完整需求、架构、功能范围和验收门槛见 [PROJECT_PLAN.zh-CN.md](PROJECT_PLAN.zh-CN.md)，每阶段实际证据及剩余工作见 [执行日志](docs/ultra/EXECUTION_LOG.md)，逐功能状态见 [台账](docs/ultra/FEATURE_STATUS.zh-CN.md)。

目前是**未签名的开发预览**，不是已经完成所有实机验收的正式发行版。代码和自动测试完成的范围不等于当前电脑的保护已经生效。没有通过订阅联网、真实 WFP 流量、Windows 多版本和浏览器策略实机验收的部分均保留未知状态。

项目继续按[完整要求 H01–H35](docs/ultra/HANDOVER_REQUIREMENTS_2026-10-26.zh-CN.md)开发。早先 beta 约定只决定发行批次，不取消后续浏览器、GPS、开源集成和 UI 目标。源码和模拟测试不能替代待完成的实机验证；最新状态以[功能台账首节](docs/ultra/FEATURE_STATUS.zh-CN.md)为准。

最新审计与整改见[第二轮台账](docs/ultra/AUDIT_RECHECK_SUMMARY.zh-CN.md)。其中服务身份认证、核心存储信任和机器恢复的源码/fake验证，与VPS固定v1的一项策略恢复分开记录；新包仍需自己的实机验收。

## 使用

1. 从本仓库 Releases 获取 `godusevpn-ultra-0.01-beta-windows-amd64.zip` 及对应 `.sha256`，核对后完整解压。本次发行仅含 Windows x64；ARM64 不在本次验收范围。
2. 只查看界面和本地检测，可运行 `godusevpn.exe`。默认请求管理员执行助手的授权；取消仍能打开应用。开发查看可用 `godusevpn.exe --ultra-no-elevate` 跳过授权。管理员助手不承载浏览器界面。
3. 要使用原有 VPN 服务，在 **64 位 PowerShell** 中运行 `./Install-Ultra.ps1 -WhatIf` 查看安装目标，再以管理员权限运行 `./Install-Ultra.ps1`。脚本仅支持新安装到系统 Program Files 下的 `GodUseVPN Ultra`，不会覆盖已有目录；失败保留文件供恢复。安装后运行安装目录中的客户端。
4. 在隐私中心逐项选择需要的保护，阅读名称旁的 `?`，再应用。程序和文件用选择器，时区用系统枚举的选择框。没有安全自动修改接口的项目提供说明和系统入口。
5. 在检测中心重新检测，查看谁仍可能读取哪些信息、证据范围和剩余限制。配置变化后须刷新检测；重新生成报告不是对旧网络快照进行独立核验。
6. 浏览器配套扩展必须手动安装到实际使用的 Chrome / Edge 配置，说明见 [browser-extension/README.md](browser-extension/README.md)。扩展检测结果只在浏览器本地，桌面端不会默默收集它。

客户端需要 Windows WebView2 运行时；本包不内置也不自动下载安装程序。缺少时按应用说明安装 Microsoft 官方运行时。上游系统要求见[上游 README](https://github.com/Maoyangui/godusevpn#readme)；Ultra 本次只构建 Windows x64，不以支持上游所有系统作为本版验收结论。文件工具暂仅接受本地固定磁盘的普通子目录，不支持移动盘、映射盘或卷根。

## 本版实际包含

- 保留原有订阅、节点、连接、模式、DNS、TUN、防直连、规则和日志；Windows 诊断增加最小摘要、明确选择和预览。Ultra 使用独立服务、数据、IPC、协议、自启、TUN 地址及 WFP GUID；默认本地端口为 12080 / 19090。
- 26 项固定隐私策略：Chrome / Edge 各 11 项，包括 WebRTC 非代理 UDP、预测加载、搜索建议、诊断、定位、相机、麦克风、通知、传感器、第三方 Cookie、WebGL；Windows 4 项为广告 ID、输入个性化、剪贴板历史及云同步。输入个性化策略不等于关闭在线语音识别；第三方应用的自行上传仍需单独限制。系统策略仅在已确认支持的版本开放修改。
- 写前备份、回读检查、持久恢复记录、外部变更冲突保护。机器策略由固定权限助手执行；当前用户浏览器策略不在替代管理员的账号中修改。
- 明确选择 Windows 时区，保留原夏令时偏好，提供备份和恢复；不按出口地址猜测，不修改 UTC 时钟或键盘。
- 独立应用 WFP 过滤器：对所选本地程序安装直接联网、私网/链路本地、组播和 IPv4 有限广播限制；查看、检查和删除自己的规则。
- 本地检测中心：实际策略、当前观察者身份、助手是否授权、已有隧道状态、应用规则安装证据、默认权限记录、时区/地区，以及网页和原生应用剩余可读范围。支持筛选、刷新和主动导出。
- 浏览器本地配套扩展：正式隐私/内容权限 API、控制权检查、撤销自身覆盖、手动追踪参数清理、范围受限的环境自测。没有全站读取权限或后台外联。
- 本地 JPEG / PNG 指定元数据块检查和清理，输出新副本，不覆盖原文件，不返回 GPS 等实际内容。不支持的格式直接说明。
- 独立 WebView2 浏览器配置编辑器：四类系统环境、地区、尺寸、WebGL vendor / renderer 和独立代理；普通用户运行，启动前配置读回，仍依赖现有 Ultra 严格隧道。系统环境为模拟，不是原生 Safari / Android 内核；真实运行时验收仍待完成。
- 可选 Chromium / Firefox 官方多版本目录和下载校验；本轮原生启动链仍在开发，明确拒绝未就绪启动。缓存校验成功不代表浏览器已运行。
- 独立 SOCKS5 / HTTP / HTTPS 代理的主动连通性和免费 GeoIP 查询；不自动调用，不回退直连。代理密码仅保留当前会话内存，不写入配置或日志。
- 可选固定 ExifTool 配套：显式选择 JPEG / PNG，默认仅显示七组 EXIF 是否存在；实际值需单独选择读取，清理输出新文件。XMP / IPTC / 缩略图等仍可能残留；该组件尚待 VM 运行验收。
- 默认关闭的秘密链接定时清空：只针对本产品复制且当前内容 / 所有者 / 序号未变的剪贴板，不承诺删除历史、云端和其他程序副本。
- 每个新增功能、操作、输入和检测项的轻量 `?`；支持鼠标、点击、键盘、Esc 和外部点击关闭。无订阅也能进入隐私和检测页面。

原版更新安装包会复用原版资源。因此 **Ultra 暂停自动获取和安装原版更新**，直到配置独立、验证过的更新通道；这是为隔离所作的明确兼容性调整。原代码的网络和连接失败策略保留，附加策略失败不会调用连接、断开或撤闸动作。

主服务身份不能确认时，界面显示“状态未知”，不会自动重装服务、登记控制者或清除防直连。响应无法确认则提示核对操作结果，不重复提交写入。服务拒绝不可信的核心数据路径；可选隐私备份失败不会被当成拒绝建立VPN隧道的条件。普通GUI对SYSTEM服务令牌的实际兼容性仍是待测门槛，不能靠提权整个界面绕过。

## 必须理解的边界

**过滤器安装不是阻断已生效的证明。** 原隧道闸的高优先级许可、其他防火墙、代理代发和不同流量层可能影响结果；本版尚未进行真实流量验收。本机回环 / localhost 没有受这些应用规则保护，不能据此宣称阻止了端口扫描或所有应用联网。

**新旧版可独立安装，整机隧道请一次只运行一个。** 网卡 IPv6、路由和 WFP 仲裁是全局资源，独立名字不能保证两套 VPN 同时运行不相互影响。不得为了双开而自动放宽防直连。

**注册表写入不是浏览器运行时验证。** 退出并重启实际浏览器后，在 `chrome://policy` / `edge://policy` 确认状态，并检查站点权限和企业例外。WebRTC 非代理 UDP 限制不是完全关闭；WebGL 策略不证明 WebGPU 被关闭。内置 WebView 和扩展来源的权限结果均不能替代任意网站或其他配置。

管理员权限不能通用禁止所有程序读取硬件参数、字体、设备标识或定位来源。本版没有通用硬件噪声、全系统 GPS 伪装、完整读取行为审计或内核级沙箱。更深的反指纹、独立浏览身份、语言/设备名修改、首次联网询问和目标白名单等项目的未完成范围见计划与执行日志；界面不提供虚假的成功开关。

检测默认不访问外部检测站、不发 STUN、不扫描局域网，也不读取 Cookie、令牌、真实公网 IP、MAC 或硬件序列号。检测导出默认不包含时区、地区及观察者身份；这些内容须主动选入，且保存用户已预览的同一快照。设置状态本身仍可能关联身份。诊断默认只有最小摘要，日志、配置、崩溃和网络详情分别选择并预览；常见凭据打码不等于匿名。图片清理只移除指定附加块，像素、文件名和其他保留块仍可能识别身份；删除 EXIF 方向可能影响显示方向。

## 恢复与卸载

1. 在**各个原用户自己的普通客户端**中逐项恢复浏览器策略和时区，或用自己的账户执行恢复命令。外部后来修改的设置会产生冲突，应用保留它们并说明，不能强制覆盖。
2. 退出安装目录中的所有 Ultra 界面及权限助手。以管理员身份运行安装目录的 `./Uninstall-Ultra.ps1 -WhatIf` 查看范围，再执行 `./Uninstall-Ultra.ps1`。
3. 卸载先检查机器策略恢复和应用过滤器清理，再调用本版服务的卸载流程恢复原有网络闸。任何必要检查失败都保留恢复工具和记录；不会因为卸载失败自动关闭其他安全保护。
4. 首版脚本保留安装文件、所有用户的设置和备份。确认恢复完成后再自行归档或删除；不要先删工具。它不替其他账户恢复 HKCU，不删除原版项目数据或服务。

新机器备份只接受SYSTEM/Administrators角色的私有对象。旧版本含具名账号权限或其他异常的备份会保留并拒绝自动使用，不会悄悄改权限、删除记录或把校验和当成来源认证；迁移须单独审查。SYSTEM机器恢复与用户HKCU恢复分开，源码修复不等于真实SYSTEM恢复已通过。

只读排查（不会自动提权、连接服务或改变配置）：

```powershell
./godusevpn-cli.exe privacy report
./godusevpn-cli.exe privacy detection
./godusevpn-cli.exe privacy firewall-list
./godusevpn-svc.exe version
```

明确恢复当前用户策略用 `privacy restore <项目ID>` 或 `privacy restore-all`；后者还会请求助手恢复机器策略。管理员 `privacy cleanup-machine` 仅供明确的机器清理流程；它不恢复其他用户或时区。不要为了读取报告而运行修改命令。

## 构建与验证

```powershell
go install github.com/tc-hib/go-winres@v0.3.3
./build-ultra.ps1
```

脚本执行 fake/临时文件回归、生成独立资源、编译 GUI/CLI/服务并生成 ZIP 和 SHA256SUMS；不启动客户端、不安装服务、不修改注册表或网络策略。已有输出目录会拒绝覆盖，便于逐版审阅。`-SkipTests` 仅用于测试已经独立记录的构建。

SHA256SUMS 用于传输完整性检查，不等于发布者签名。CI 和自动回归通过不等于发布验收完成。服务和策略的实机验证须在可恢复的 Windows 测试环境分别记录，包含 UAC 取消、受管浏览器、冲突恢复、重启、严格闸、代理代发和 loopback；未取得证据的项目继续列为待验收，检测保留未知或未验证。未覆盖的系统版本或流量场景不宣称已验证。

接口依据：[Windows WFP 仲裁](https://learn.microsoft.com/en-us/windows/win32/fwp/filter-arbitration)、[Edge WebRTC 策略](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/webrtclocalhostiphandling)、[Chrome WebGL 策略](https://chromeenterprise.google/policies/disable3-dap-is/)。其余具体策略来源保留在固定 catalog 和界面说明中。
